# 5–10 Minute Demo

1. Introduce the problem and NetSage AI.
2. Open `cases.csv` and show the 30 cases.
3. Open the Streamlit dashboard.
4. Select a broken routing/VLAN case.
5. Run AI diagnosis.
6. Explain root cause, confidence and evidence.
7. Show deterministic rule checker.
8. Select a human review decision.
9. Show review log.
10. Show dashboard agreement metrics.
11. Open the corresponding Packet Tracer topology.
12. Run the suggested diagnostic command.
13. Fix the issue manually.
14. Verify connectivity.
15. Explain responsible-AI safeguards.
