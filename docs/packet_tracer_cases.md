# Packet Tracer Case Guide

For each final case:
1. Build a working topology.
2. Verify connectivity.
3. Introduce one primary fault.
4. Run Cisco show commands.
5. Record actual output.
6. Save the `.pkt` file.
7. Add evidence to `cases.csv`.
8. Run NetSage.
9. Human review.
10. Fix manually.
11. Verify connectivity.

Useful commands:
```text
show ip interface brief
show running-config
show vlan brief
show interfaces trunk
show ip route
show access-lists
show ip nat translations
show ip nat statistics
show ip dhcp binding
show ip dhcp pool
show interfaces
show arp
show cdp neighbors
```

Do not invent final Packet Tracer evidence.
